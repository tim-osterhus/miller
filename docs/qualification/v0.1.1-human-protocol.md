## Accepted v0.1.1 limitation and v0.1.2 batch

The owner accepted the following nonblocking limitation for the v0.1.1 source
release after testing the release candidate on 2026-08-08. Visible Live Voice
transcript text can be selected with the pointer and copied through the native
context menu, but Command-C does not copy the active transcript selection and
instead produces the macOS alert sound. Pointer selection also stops at line
breaks rather than spanning multiple visible lines. Context-menu copies paste
correctly, Markdown renders correctly, and a rendered link opens in the
external browser. No copied transcript content is recorded here.

The v0.1.2 update batch therefore includes:

- repair native Command-C routing for selectable typed and Live Voice
  transcript text in both the overlay and full conversation window;
- allow a pointer selection to span line breaks across rendered transcript
  blocks while preserving Markdown and code-block presentation; and
- integrate and qualify the already completed source-only custom wake-phrase
  foundation, which remains absent from the v0.1.1 application package.

The Command-C limitation does not block v0.1.1 because pointer selection and
the native context-menu Copy path work, and the owner explicitly chose to
defer the keyboard-equivalent repair.
